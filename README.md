# PawMate

湘南エリアの飼い主と有資格プロのケアラーをつなぐ、信頼可視化型ペットケアサービスのプロトタイプです。

## ローカル起動

```bash
npm install
npm run dev
```

## ビルド

```bash
npm run build
```

## 現在の範囲

- Vite + React + TypeScript の静的プロトタイプ
- LP、ケアラー検索、依頼掲示板、登録、予約、メッセージ、管理者審査のデモ画面
- 本番DB、実認証、Stripe Connect、eKYCは未実装
- `pawmate-full.html` は移植元の参照ファイルとして保持
