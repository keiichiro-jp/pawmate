# PawMate リスク分析と対策
くじら舎 ／ v1.0 ／ 2026.05.31

---

## リスクの整理方針

リスクを「発生確率」と「影響度」の2軸で評価する。
対策は「予防（起きないようにする）」と「対応（起きたときどうするか）」の両方を設計する。

```
影響度
  高  │ [C] 法規制変更    [A] 重大事故
      │ [D] ペットゴー本格参入
  中  │ [F] ケアラー離脱   [B] 情報漏洩
      │ [G] 資金ショート
  低  │ [H] 競合新規参入   [E] 悪質ユーザー
      ├──────────────────────────────
      │   低              中         高
                                  発生確率
```

| # | リスク | 確率 | 影響 | 優先度 |
|---|--------|------|------|--------|
| A | ペットの重大事故 | 低 | 高 | **最優先** |
| B | 個人情報・決済情報の漏洩 | 低 | 高 | **最優先** |
| C | 法規制の強化・行政指導 | 中 | 高 | **高** |
| D | ペットゴー+DogHuggyの湘南本格展開 | 中 | 高 | **高** |
| E | 悪質ユーザー（ケアラー・飼い主） | 中 | 中 | **中** |
| F | ケアラーの大量離脱 | 中 | 中 | **中** |
| G | 資金ショート | 低 | 中 | **中** |
| H | 新規競合の参入 | 高 | 低 | **低** |

## A｜ペットの重大事故

**内容：** ケア中にペットが死亡・重傷・脱走するリスク。プラットフォームの信頼が一瞬で崩壊する可能性がある最大のリスク。

### 予防策

**① 有資格者のみ登録（最大の予防）**
第一種動物取扱業登録済みのプロのみがケアラーになれる設計。素人によるアクシデントをそもそも排除する。

**② Meet & Greet の必須化**
初回予約前に飼い主・ペット・ケアラーが顔合わせ。ペットの性格・持病・アレルギー・緊急時の連絡先を書面で確認する。

**③ ケアラー向け緊急対応マニュアルの整備**
- 熱中症・誤飲・脱走・噛まれた際の初動対応
- 提携獣医師への緊急連絡先リスト（湘南エリア）
- 24時間対応の緊急ホットライン設置（フェーズ2以降）

**④ GPS追跡の義務化**
散歩中のリアルタイム位置情報をプラットフォームが記録。脱走時の早期発見に使える。

### 対応策（事故発生時）

```
[発生] ケアラーから緊急連絡
  ↓
[初動] 30分以内にプラットフォームが飼い主に連絡
  ↓
[対応] 提携獣医師への搬送を判断・サポート
  ↓
[補償] 保険スキームの適用（治療費・賠償）
  ↓
[検証] 事故原因の調査・再発防止策の設計
  ↓
[開示] 必要に応じて飼い主・関係者への報告
```

**保険設計（最重要）：**
損保ジャパン・東京海上等の大手損害保険会社と包括契約を結ぶ。カバー範囲：ペットの治療費（上限100〜200万円）・第三者への賠償・物損。フェーズ0で必ず交渉を始める。

## B｜個人情報・決済情報の漏洩

**内容：** 飼い主の住所・鍵の預かり情報・決済情報が漏洩するリスク。ペットケアの性質上、住所は必ず扱う。

### 予防策

**① 決済はStripeに任せる（自社で持たない）**
カード番号・銀行口座情報はStripeが管理。PawMateのサーバーには一切保存しない。

**② 鍵情報のアプリ外共有の禁止**
鍵の受け渡しはアプリ内のチャットで記録。物理的な鍵の預かり証もアプリ内で発行する設計にする。

**③ eKYC（本人確認）をケアラーに義務化**
運転免許証・マイナンバーカードによる実名確認。身元不明者の排除。

**④ データの最小化**
取得する個人情報を必要最小限にする。住所は配送先ではなく「エリア」として管理する。

**⑤ セキュリティ監査の定期実施**
フェーズ2以降、外部セキュリティ企業による脆弱性診断を年1回実施。

### 対応策（漏洩発生時）

- 72時間以内の個人情報保護委員会への報告（義務）
- 影響を受けたユーザーへの即時通知
- 弁護士・セキュリティ専門家のチームへの連絡体制を事前に確保

## C｜法規制の強化・行政指導

**内容：** 動物愛護管理法の改正や行政の解釈変更により、プラットフォームの運営スキームが違法とみなされるリスク。

### 現状の法的グレーゾーン

「マッチングの場の提供者」としてのプラットフォームが、動物取扱業の登録義務を負うかどうかは自治体によって解釈が異なる可能性がある。

### 予防策

**① フェーズ0で保健所への事前相談を必ず実施**
神奈川県動物愛護センターに事業モデルを説明し、法的スキームの確認を取る。グレーゾーンを排除した状態でスタートする。

**② ケアラーが個人事業主として契約する構造を明確化**
プラットフォームは「場所と機会の提供者」。契約の当事者はケアラー個人（個人事業主）と飼い主。この構造を利用規約に明記する。

**③ 法改正のモニタリング**
環境省・農林水産省の動物愛護管理法関連の動きを定期的にチェック。弁護士との顧問契約をフェーズ2以降で検討。

**④ ケアラーの資格取得を支援することで「有資格者のみ」を維持**
規制が強化されても、すでに有資格者のみのプラットフォームであれば影響が最小化される。

### 対応策（行政指導を受けた場合）

- 弁護士と即時相談
- 指摘内容に応じて運営スキームを修正
- ケアラー・飼い主への誠実な説明と対応

## D｜ペットゴー+DogHuggyの湘南本格展開

**内容：** ペットゴーが270万人の顧客基盤とFLAFFYのSNSネットワークを使って湘南エリアでDogHuggyを本格展開するリスク。現在PMI実施中だが、統合が完了すれば強力な競合になる。

### 現状分析

- DogHuggyは現在PMI実施中で、湘南での供給側（ホスト）はまだ薄い
- ペットゴーの顧客の15.4%が神奈川在住 → いずれ来る
- DogHuggyは「一般愛犬家（ドッグホスト）」モデル → 有資格プロとは別の土俵

### 予防策

**① PawMateが動く前にDogHuggyが湘南を制圧することを防ぐ**
スピードが最大の対策。フェーズ0〜1を速く動き、「茅ヶ崎のペットケアといえばPawMate」の状態を先に作る。

**② 有資格プロという参入障壁を高く保つ**
DogHuggyは一般愛犬家も登録できる。PawMateは有資格プロのみ。この差を飼い主に明確に伝え続ける。

**③ ケアラーとの関係性を深める**
ケアラーがPawMateを「自分のプラットフォーム」と感じるよう設計する。待遇改善・フィードバックの反映・コミュニティ形成。一度PawMateに根付いたケアラーはDogHuggyには移らない。

**④ 湘南の地域密着ブランドを作る**
「湘南発のローカルサービス」というアイデンティティは大手プラットフォームが真似できない。地域のペットイベント・動物病院・ドッグランとの連携がブランドの堀になる。

### 対応策（DogHuggyが本格参入した場合）

- 差別化軸（有資格プロ・地域密着）を強化する方向で対応
- 価格競争には絶対に乗らない
- むしろペットゴーとの提携・買収の可能性を検討する選択肢も持っておく（フェーズ3以降）

## E｜悪質ユーザー（ケアラー・飼い主）

**内容：** 虚偽のプロフィールで登録したケアラーによる詐欺・窃盗、または飼い主による不当なクレーム・評価操作。

### 予防策

**ケアラー側：**
- eKYC（身元確認）の義務化
- 動物取扱業登録番号の確認（行政データとの照合）
- 審査フロー（管理者承認制）
- 試用期間の設置（最初の3件はプラットフォームが重点モニタリング）

**飼い主側：**
- 実名・連絡先の確認
- 悪質なキャンセル・クレームへのペナルティ設計（キャンセル料・アカウント停止）
- 相互評価制度（ケアラーも飼い主を評価できる）

### 対応策

- 問題ユーザーの即座のアカウント停止権限を管理者が持つ
- 紛争解決フローの明文化（利用規約に明記）
- 警察・弁護士への連携体制を事前に確保

---

## F｜ケアラーの大量離脱

**内容：** 登録ケアラーが一斉に離脱し、供給側が崩壊するリスク。特にフェーズ1の初期ケアラーが離れると立て直しが困難。

### 主な離脱理由と対策

| 離脱理由 | 対策 |
|---------|------|
| 手数料が高いと感じる | ケアラー負担18%を死守・Wagの40%との対比を共有・飼い主側7%との併用を説明 |
| 案件が入ってこない | 供給より需要を先に作る。初期ケアラーへの優先送客 |
| プラットフォームが使いにくい | ケアラーのフィードバックを即座に反映 |
| 自分で顧客を作れた | 「PawMate経由の顧客」として継続利用を促す仕組み |
| 競合に移る | ケアラーコミュニティの形成・帰属意識の醸成 |

### 予防策（ケアラー定着の設計）

- **月次の稼働レポート送付**（「今月の収入・件数・リピート率」をケアラーに毎月送る）
- **トップケアラー制度**（リピート率・評価上位者をプロフィールで「認定ケアラー」として表示）
- **ケアラー向けコミュニティ**（Slackまたはグループチャットで情報共有・相談できる場を作る）
- **フィードバック会議**（月1回、ケアラーと改善点を話し合う場を設ける）

## G｜資金ショート

**内容：** 予想より収益が立ち上がらず、運営費が尽きるリスク。

### 予防策

**① フェーズ1は黒字スタート設計**
月間コスト約12万円に対して、月間収益約20万円を見込む構造。赤字にならない設計でスタートする。

**② 固定費を最小化する**
- システム：Vercel（無料〜月数千円）・Supabase（無料〜月数千円）
- 広告：フェーズ1はゼロ
- 人件費：Keiさん1人でフェーズ1を回す

**③ キャッシュフローを毎週確認する**
「残高が3ヶ月分を切ったら警戒」というルールを設ける。

### 対応策（資金が厳しくなった場合）

- 広告費の即時カット
- ケアラー審査登録料の引き上げ
- くじら舎の他事業からの一時的な資金融通
- 政策金融公庫の創業融資（500万円程度まで無担保で借入可能）

## H｜新規競合の参入

**内容：** 湘南エリアに特化した新しいペットケアサービスが登場するリスク。

### 評価

**発生確率は高いが、影響度は低い。**

なぜなら：
- 有資格プロのネットワーク構築には時間がかかる
- 地域密着ブランドは一度確立すれば簡単には崩れない
- チカ先生・Hey!Dogsとの関係性は複製できない

### 対応策

真似されたら「より良くする」だけ。競合を意識して戦略を変えない。

## リスク対策の優先実施事項（フェーズ0でやること）

```
① 保険スキームの交渉開始（損保ジャパン等）        ← 最優先
② 神奈川県動物愛護センターへの法的スキーム確認    ← 最優先
③ 利用規約・プライバシーポリシーの弁護士確認      ← 高
④ eKYC（本人確認）フローの実装                    ← 高
⑤ 緊急時対応マニュアルの作成                      ← 高
⑥ Stripe Connectの本番環境構築                    ← 中
```
