# PawMate STP設計
くじら舎 ／ v1.0 ／ 2026.05.31

---

## S｜Segmentation — 市場を切る

ペットケア代理市場を2軸で切る。

**軸1：ケアの緊急性・頻度**
- スポット型（旅行・出張・急用の単発利用）
- 定期型（毎週・毎月の日常的な継続利用）

**軸2：信頼への感度**
- 低感度（とにかく安ければいい）
- 高感度（誰が来るかが最重要）

これで4象限が生まれる。

| | 低信頼感度 | 高信頼感度 |
|---|---|---|
| **スポット型** | ① 価格重視・単発層 | ② 安心重視・単発層 |
| **定期型** | ③ 習慣化・低関与層 | ④ 関係性重視・定期層 |

### 各セグメントの実態

**① 価格重視・単発層**
くらしのマーケット・ジモティーを使う層。「誰でもいいから安く」。PawMateのターゲットではない。

**② 安心重視・単発層**
旅行・帰省時に「信頼できる人に頼みたいが知り合いがいない」層。現在ペットホテルに流れている。潜在規模が最大。ただし利用頻度が低いのでLTVが伸びにくい。

**③ 習慣化・低関与層**
散歩代行を日課にしているが、誰でもいい層。単価競争に巻き込まれやすい。

**④ 関係性重視・定期層**
「同じ人に定期的に来てもらいたい」「ペットのことをわかってくれる人を確保したい」層。LTVが最も高く、ケアラー側の収益も安定する。PawMateの本丸。

## T｜Targeting — 誰を狙うか

### メインターゲット：飼い主（需要側）

**PRIMARY｜関係性重視・定期利用層**

```
30〜50代・共働き世帯
犬または猫を飼育（特にシニアペット・多頭飼い）
湘南エリア在住（茅ヶ崎・藤沢・鎌倉・平塚・辻堂）
世帯年収600万円以上
「いつもの人」に頼みたい
ペットホテルは嫌い（環境変化によるストレスを気にする）
```

**なぜここか：**
定期利用はLTVが高く、プラットフォームの粗利が積み上がる。同一ケアラーとの継続関係は信頼障壁を自然に解消する。CAC回収が早い。

**SECONDARY｜安心重視・単発層（旅行・出張）**

```
30〜50代・ペットを家族と認識している層
年2〜4回の旅行・出張時に利用
「ペットホテルより自宅でケアしてほしい」
初回利用でリピーターに転換できれば価値大
```

**なぜここか：**
入口として機能する。体験が良ければ定期利用に転換する。DogHuggyが取り込めていなかった「自宅訪問型」のニーズ。

---

### メインターゲット：ケアラー（供給側）

**PRIMARY｜有資格・個人開業者**

```
第一種動物取扱業（保管・訓練）登録済み
個人または小規模事業者
開業1〜5年目
集客・予約管理・決済に課題を感じている
「ケアに集中したいが営業が苦手」
```

**なぜここか：**
法規制をすでにクリアしている。PawMateへの参加コストが最小。集客課題を解決してあげることで動機づけが強い。

**SECONDARY｜ドッグトレーナー（訓練士）**

```
JKC公認訓練士・警察犬協会公認等の有資格者
訓練業で登録済みだが保管業は未登録の可能性あり
見習い期間の待遇への不満を持つ層
副収入としてシッティング・散歩代行を追加したい
```

**なぜここか：**
チカ先生・Hey!DogsのネットワークからリーチできるWarm Lead。「訓練 × ケア」のセットで提供できれば他にない価値になる。

## P｜Positioning — どこに立つか

### ポジショニングマップ

2軸：**信頼性（低→高）× ケアの専門性（アマチュア→プロ）**

```
                    専門性：高
                        |
            CarePets    |    PawMate ← ここ
            （看護師系） |   （有資格プロ×地域密着）
                        |
低信頼 ───────────────────────────────── 高信頼
                        |
  くらしのマーケット     |    DogHuggy
  ジモティー            |  （一般愛犬家×審査あり）
                        |
                    専門性：低
```

PawMateは右上の象限を独占する。ここに強い競合はいない。

---

### ポジショニング・ステートメント

**飼い主向け：**
> 「信頼できるプロが、いつもの場所で、いつものように。」

有資格者のみが登録できるプラットフォームであることを前面に出す。「誰が来るかわからない」という最大の不安を、登録番号・資格バッジ・事前面談で解消する。

**ケアラー向け：**
> 「あなたはケアだけに集中していい。」

集客・予約・決済・報告はPawMateが引き受ける。プロとして正当に稼げる場所を提供する。

### 価格ポジション

安売りしない。有資格プロの品質に見合った価格を設定する。

| サービス | PawMate価格帯 | 市場中央値 |
|---------|--------------|-----------|
| 散歩代行30分 | 2,500〜3,500円 | 2,700〜3,000円 |
| 訪問ケア60分 | 4,000〜5,500円 | 4,000〜5,000円 |
| 宿泊 | 15,000〜25,000円 | 15,000〜44,000円 |

市場中央値と同水準〜やや上。「安さ」ではなく「信頼と専門性」で選ばれる設計にする。

## STP総括

| | 内容 |
|---|---|
| **戦う市場** | 湘南エリアの定期利用×高信頼ニーズ層。スポット単発は入口として使うが主戦場ではない |
| **狙うターゲット** | 需要側：共働き・シニアペット・関係性重視の30〜50代。供給側：集客課題を抱える有資格個人事業者 |
| **立つポジション** | 「有資格プロ×地域密着×ケアラー待遇改善」。専門性と信頼性の右上象限を独占する |
