#### CASE 1｜ペット体調不良

**判定基準（以下いずれかに該当したらケアラーはKeiへ即報告）**
- 食欲がない（いつもの半分以下）
- 嘔吐・下痢が2回以上
- ぐったりしている・立ち上がれない
- 呼吸が荒い・口呼吸している
- 出血・けが・骨折疑い
- 5分以上意識がない・けいれん

| 状態 | 初動（ケアラー） | 連絡先・タイムライン | 運営（Kei）の判断 |
|---|---|---|---|
| 軽症（元気だが食欲なし、1回の軟便等） | ①様子を写真撮影 ②Keiへ5分以内にLINE報告 | Kei → 飼い主へ状況共有（15分以内） | 飼い主の指示に従う |
| 中症（嘔吐2回以上・ぐったり） | ①安全な場所に移動 ②Keiへ即電話 ③飼い主へ並行連絡 | Kei → 飼い主へ即電話。飼い主と相談し病院判断 | **飼い主判断を最優先**。Keiは橋渡しに徹する |
| 重症（意識なし・けいれん・大量出血） | ①かかりつけ病院へ即電話（または夜間救急へ） ②飼い主へ即電話 ③Keiへ並行連絡 | **病院対応最優先**。10分以内に飼い主連絡 | Keiは病院・飼い主・ケアラーの橋渡し。保険会社に事故報告の必要性を確認（⚠️保険） |

**⚠️ 保険**：ペット怪我・死亡は保険請求対象となりうる。事故報告は「発生から24時間以内」が多くの保険で必須条件。保険未確保の場合は事後補償なし。

#### CASE 5｜事故発生時（最重要）

**定義**：ペットの死亡・重傷・他者への咬傷・飼い主宅での財物損壊・ケアラーの負傷

```
【初動フロー（最初の10分）】

発生確認
  ↓
① ペット・関係者の安全確保（最優先）
  ↓
② 飼い主へ電話（LINEでなく電話。繋がらなければ予備番号）
  ↓
③ Keiへ電話（飼い主連絡と並行またはその後即時）
  ↓
④ 必要なら救急・動物病院へ電話
  ↓
【その後30分以内】
⑤ 状況を写真・動画・文章で記録（証拠保全）
⑥ 保険会社へ事故発生の第一報（⚠️保険：多くは24時間以内が必須）
⑦ Keiが事故報告書ドラフトを作成開始

【24時間以内】
⑧ 事故報告書を正式作成
⑨ 飼い主・ケアラーから事情聴取（書面または電話）
⑩ 保険会社へ正式報告

【48〜72時間以内】
⑪ 対応方針を確定（補償・謝罪・再発防止）
⑫ 飼い主へ対応方針を説明

```

**⚠️ 保険**：P0-006完了前の初回取引での事故はPawMateが全額負担となるリスクがある。フェーズ1開始前に保険スキームを確定すること。

**⚠️ 法務**：ケアラーが動物取扱業未登録の状態での事故は、行政指導・損害賠償の対象になりうる。登録確認（P1-002）完了前は取引を開始しない。

**⚠️ 個人情報**：事故報告に含まれる飼い主情報・ペット情報は関係者外に共有しない。保険会社への提出は必要最小限にとどめる。

#### 0｜PawMateのケアラーとして大切にしてほしいこと

1. **ペットの安全が最優先**。何か迷ったら「これはペットにとって安全か？」を自問する。

3. **飼い主の「安心」を届ける**。写真1枚とひと言で、飼い主の不安は大幅に減る。

#### 2｜ケア中の記録方法

**基本ルール**
- ケア開始時・終了時は必ずKeiへLINE報告する
- 写真は最低3枚撮る（ケア開始直後・ケア中・終了直前）
- ペットの様子で少しでも気になることがあれば記録する

**写真撮影のポイント**

| 目的 | 撮影タイミング | コツ |
|---|---|---|
| 安心感を届ける | ケア開始後30分以内 | 明るい場所でペットの顔が見える構図。楽しそう・リラックスしている瞬間を選ぶ |
| 状態の記録 | 食事前後・排泄後 | 食べた量・残量が分かる写真。排泄物の状態が気になる場合は記録（飼い主へ送る必要はなし） |
| トラブル記録 | 異常を発見した瞬間 | 証拠として客観的に記録。傷・嘔吐物・破損物なども撮影しておく |

**⚠️ 個人情報**：飼い主の住宅内の写真はSNSや個人アカウントには絶対に投稿しない。写真はPawMateアプリ経由でのみ共有する。

---

#### 3｜報告カードの書き方

報告カードはケア終了後、**30分以内に送信する**。

**各項目の記入ガイド**

| 項目 | 記入内容 | 例 |
|---|---|---|
| 気分・状態 | 5段階で選択。迷ったら「普通（3）」より少し正直に | 元気いっぱいに走り回っていたら「5：とても元気」 |
| 食事 | 完食・半分・ほぼ残した・食べなかったで選択 | 「完食。いつもより早かった」 |
| 排泄 | 回数と形状を記録。気になった点があれば一言 | 「散歩中に2回。軟らかめだったため記録」 |
| ケアメモ | ケアの内容・気になったこと・次の人への申し送り | 「散歩で◯◯公園まで行きました。帰宅後は水をよく飲みました」 |
| 注意事項 | 飼い主に伝えるべきこと | 「右前足を少し気にする様子あり。動物病院に確認をおすすめします」 |
| 写真 | 最低1枚。できれば3枚 | 散歩中の写真・ご飯を食べている写真・くつろいでいる写真 |
| GPS | アプリの「GPS記録」ボタンをケア開始時にONにする | 散歩ルートが自動記録される |

**書いてはいけないこと**
- 個人の意見・批判（「飼い主の部屋が汚い」など）
- 確認していないことを「〇〇でした」と断言すること
- 飼い主を不必要に不安にさせる表現（「なんか様子が変でした」→「右前足を少し気にする様子がありました」に言い換える）

---

#### 4｜GPS記録のルール

- 散歩・訪問ケア時は必ずアプリの「GPS記録」をONにしてからケアを開始する
- GPS記録はペットの安全確認・経路確認のためのもの。飼い主への提出が目的
- 個人的にケアラー自身の位置情報を他者と共有しない
- 電池残量が少ない場合はGPS記録前にKeiへ連絡する

#### 5｜飼い主とのコミュニケーションルール

**基本**
- 連絡はすべてPawMateアプリ内またはKei経由で行う（フェーズ1はLINEで代替可）
- 飼い主の個人連絡先はPawMate業務以外に使用しない
- 丁寧語を基本とする。でも固くなりすぎない（「元気でした！」は普通のトーン）

**連絡タイミング（標準）**

| タイミング | 内容 | 手段 |
|---|---|---|
| ケア開始時 | 「〇時に到着しました。〇〇ちゃん元気です」+ 写真1枚 | LINE/アプリ |

| ケア終了時 | 「〇時に終わりました。報告カードをお送りしました」 | LINE/アプリ |
| 気になることがあった時 | 即連絡。テキスト → 返信なければ電話 | LINE → 電話 |

**飼い主からクレームを受けた場合**
1. まず謝罪する（「ご不便をおかけし申し訳ありません」）
2. 内容を正確にメモする
3. 「確認してから改めてご連絡します」と伝える（その場での判断は不要）
4. **Keiへ即連絡**。対応はKei判断に委ねる

#### 6｜緊急時対応

**緊急の判定基準（CASE 1の判定基準と共通）**
- ぐったりしている・立ち上がれない
- 呼吸が荒い・口呼吸している
- 2回以上の嘔吐・下痢
- 出血・けが・骨折疑い
- 意識がない・けいれん

**緊急時の行動手順**

```
① ペットを安全な場所に移す（危険物・段差・他の動物から遠ざける）
② かかりつけ動物病院へ電話する（事前に番号を把握しておく）
③ Keiへ電話する（LINEでなく電話）
④ 飼い主へ電話する（Keiと並行で連絡）
⑤ 状況を写真・動画で記録する（後から証拠として必要になる）
⑥ 病院へ連れて行く場合：飼い主の同意を得てから。費用は後精算
⑦ Keiの指示に従って行動する
```

**飼い主の代わりに病院に連れて行ける条件**
- 飼い主または Kei から口頭・LINEで「お願いします」の指示があること
- 飼い主が遠方にいて連絡がつかない場合は、Kei判断で動く

#### 7｜キャンセル・遅刻時の連絡ルール

**ケアラーからのキャンセル・遅刻**

| 状況 | 連絡のタイミング | 連絡先 |
|---|---|---|
| 遅刻が確定した瞬間 | 即座に | Kei → Keiが飼い主へ連絡 |
| 当日キャンセルが確定した瞬間 | 即座に | Kei → Keiが飼い主へ連絡 |
| 前日までのキャンセル | できるだけ早く | Kei |

**キャンセル連絡テンプレート（ケアラー → Kei）**

```
Keiさん、〇月〇日のケアについてご連絡があります。
[理由：体調不良 / 家族の緊急事態 / その他 ]のため、
[遅刻予定：〇分程度 / キャンセル] となってしまいます。

大変申し訳ありません。対応をよろしくお願いいたします。
```

**ペナルティについて**
- 当日キャンセル・30分超の遅刻は、評価スコアに反映される
- やむを得ない事由は記録するが、繰り返しの場合は新規案件の配分を制限する
- 事前予告なく無断で来なかった場合は、PawMateから案件を受け取れなくなる場合がある

#### 8｜安全・衛生管理

- 他のペットをケアする場合は、手洗い・着替え・道具の消毒を行う（感染症・ノミ・ダニの持ち込み防止）
- ケア中に飼い主宅の食べ物・飲み物を無断で使用しない
- ゴミを持ち出す場合は飼い主の許可を得る
- 貴重品・現金には触れない（「ない」「あった」のトラブルを防ぐ）
- 帰宅時は入室ルート・施錠を必ず確認してから退室する

#### 9｜よくある質問（FAQ）

**Q: 飼い主から「次回もあなたにお願いしたい」と言われた。アプリ外で直接取引してよい？**
A: NG。すべての取引はPawMate経由で行う。アプリ外の直接取引は契約違反となり、保険も適用されなくなる。

**Q: ペットが暴れて手を噛まれた。どうすればよい？**
A: ①傷の状態を確認 ②必要であれば医療機関へ ③Keiへ報告。ケアラー自身の怪我については、個人で入っている傷害保険が基本（PawMateフェーズ1では労災適用外）。

**Q: 飼い主から「このまま今日も何時間か預かってほしい」と言われた。当初の契約時間を超えても対応してよい？**
A: ①Keiへ連絡 ②延長分の料金確認 ③Keiが承諾した場合のみ対応。自己判断でサービス範囲を拡大しない。

**Q: ケア中に飼い主の大切な物を壊してしまった。どうすればよい？**
A: ①Keiへ即連絡 ②壊れたものの写真を撮る ③飼い主へ謝罪する ④補償についてはKei判断。自分で判断して補償額を提示しない。
