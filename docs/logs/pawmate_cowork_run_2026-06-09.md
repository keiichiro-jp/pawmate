#### 登録確認フルワークフロー

```
Step 1: 候補者へ確認依頼送付
  ├ 送付内容: 確認依頼文 + 提出書類リスト
  └ 提出先: Kei のクラウドストレージ（候補者1人1フォルダ）

Step 2: 提出物の受領確認
  ├ 必須提出物
  │   ├ 動物取扱業登録証（写し）
  │   ├ 本人確認書類（免許証等の写し）
  │   └ 稼働エリア・対応サービス記載の簡単なシート
  └ 受領後: 候補管理表の「書類受領」欄に日付を記録

Step 3: 登録証の確認
  ├ 確認チェックリスト（06-05 版）を使用
  ├ 合格: 候補管理表を「登録確認済み」に更新
  ├ 期限切れ/申請中: 候補者に更新・取得手順を案内
  └ 登録なし/登録意向なし: 候補管理表を「候補外」に分類

Step 4: 確認完了の記録
  ├ 確認日・確認者（Kei）を候補管理表に記録
  ├ 登録番号・種別・有効期限を PawMate データに入力
  └ 次ステップ: PM-RM-P1-003（プロフィール作成）の対象に追加

Step 5: 年次更新管理
  └ 有効期限の3ヶ月前に候補者へ更新確認の連絡を送る
```

#### Meet & Greet 予約フロー 仕様書

