## PawMateとは何か

**湘南エリア（茅ヶ崎・藤沢・鎌倉・平塚・辻堂）で先行スタートする、ペットケアマッチングプラットフォームです。**

ペットの飼い主と、有資格のケアラーをつなぎます。  
サービス内容は散歩代行・訪問ケア・宿泊お預かりの3種類。

### 普通のマッチングと何が違うか

世の中にはDogHuggyやくらしのマーケットなど、似たようなサービスがあります。  
それらとPawMateは、根本的に違う設計になっています。

**他のサービス：** 「誰でも登録できる。安ければいい。」  
**PawMate：** 「第一種動物取扱業の登録がある、プロだけが登録できる。」

つまり、**あなたのような有資格者が初めて正当に評価される場所**です。

素人と同じ土俵で価格競争する必要は、もうありません。

## あなたが得られるもの

### 1. 集客はPawMateがやります

個人で開業したシッターの最大の悩みは集客です。  
ホームページを作り、SNSを運用し、口コミを積み上げる。  
軌道に乗るまで6〜12ヶ月、その間は収入がほぼゼロ。

PawMateに登録すれば、飼い主側からの予約が入ってきます。  
あなたがやることは、ケアだけです。

### 2. 予約・決済・報告の管理も引き受けます

- 予約のやり取り → プラットフォーム内チャットで完結
- 代金の回収 → Stripe決済で事前に完了。現金不要
- サービス報告 → アプリから写真付きで送信

事務作業に使っていた時間を、ケアに使えます。

### 3. 「訓練 × ケア」のセットで収入が跳ね上がる

これが最も重要なポイントです。

訓練レッスンは、1頭あたりの接触回数が限られます。  
でも散歩代行・シッティングは**週複数回の定期収入**になります。

すでに訓練で信頼関係がある飼い主に、  
「散歩も私に任せてください」と言うだけでいい。

これがPawMate経由でできるようになります。

## 収入シミュレーション

### ケース①｜週3日・隙間で入れる場合

```
散歩代行 30分 × 3,000円
週3日 × 1日3件 = 週9件
月36件 × 3,000円 = 月108,000円（グロス）
ケアラー手数料18%控除後 → 月88,560円
```

**訓練収入に月8.9万円のプラス。**

### ケース②｜週5日・本格的に組み合わせる場合

```
散歩代行 30分 × 3,000円
週5日 × 1日4件 = 週20件
月80件 × 3,000円 = 月240,000円（グロス）
ケアラー手数料18%控除後 → 月196,800円
```

**訓練収入に月19.7万円のプラス。**  
正社員トレーナーの年収（250〜320万円）を、個人で超えられます。

### ケース③｜定期契約が取れた場合

同じ飼い主から週3回の定期散歩代行を受けると：

```
3,000円 × 週3回 × 月4週 = 月36,000円（1世帯から）
これが5世帯つけば → 月180,000円（グロス）
手数料18%控除後 → 月147,600円（安定収入）
```

定期契約は収入が読めます。繁忙期・閑散期の波もなくなります。

## 登録の条件

PawMateは誰でも登録できるわけではありません。  
以下を満たしている方のみ登録できます。

```
✓ 第一種動物取扱業（保管 または 訓練）の登録があること
✓ 神奈川県の湘南エリアで活動できること
  （茅ヶ崎・藤沢・鎌倉・平塚・辻堂）
✓ 初回の事前面談（飼い主との顔合わせ）に対応できること
```

**「保管業」の登録がない場合もご相談ください。**  
登録取得のサポートも一緒に考えます。

## 手数料について

PawMate経由で成約した案件に対して、**売上の18%**をケアラー手数料としていただきます。（飼い主側にも別途7%を課金するデュアルフィー方式ですが、これはあなたの取り分には影響しません）

| 売上 | ケアラー手数料18% | あなたの手取り |
|------|--------|--------------|
| 3,000円（散歩30分） | 540円 | 2,460円 |
| 4,500円（訪問ケア60分） | 810円 | 3,690円 |
| 20,000円（宿泊1泊） | 3,600円 | 16,400円 |

**Wagのような海外サービスは40%を取ります。PawMateは18%です。** あなたの技術と時間に正当に報いる設計です。

自分のサイトで直接受けた案件には手数料はかかりません。  
PawMate経由で来た案件だけが対象です。

## あなたに正直に伝えること

PawMateはまだ立ち上げ段階です。  
湘南エリアでの先行サービスを、これから一緒に作り上げたいと思っています。

だからこそ、最初に参加してくれる方には特別な関係を築きたいと思っています。

- あなたのフィードバックがサービスの設計に直接反映されます
- 最初期のケアラーとして、プロフィールが上位に表示されます
- 将来のサービス拡張（エリア拡大・新機能）に一緒に関われます

「使う側」ではなく、**「一緒に作る側」**として参加してほしいのです。
