# PawMate 運営スキームの動物取扱業上の扱い
くじら舎 ／ v1.0 ／ 2026.05.31

---

## 1. 結論

PawMate は、設計を誤ると運営会社自身が第一種動物取扱業「保管」と見られるリスクがある。

一方で、以下の建て付けを徹底すれば、PawMate 運営会社は「飼い主と登録済みケアラーをつなぐオンラインプラットフォーム」として整理し、実際に動物を預かるケアラー側が第一種動物取扱業「保管」の登録を持つ形で運用できる可能性が高い。

```
飼い主
  ↓ 直接契約
登録済みケアラー（第一種動物取扱業・保管）
  ↑
PawMate：予約・決済・審査・情報提供・安全管理の場
```

ただし、行政判断は自治体ごとに実務差があり得る。PawMate は神奈川県・湘南エリアから始めるため、営業開始前に神奈川県動物愛護センターまたは管轄自治体へ、事業スキーム図と規約案を持参して事前相談するべきである。

## 2. 法令上の基本整理

### 2-1. 第一種動物取扱業とは

環境省は、業として動物の販売、保管、貸出し、訓練、展示、競りあっせん、譲受飼養を営利目的で行う場合、営業開始前に登録が必要としている。

対象は、実験動物・産業動物を除く、哺乳類・鳥類・爬虫類である。

### 2-2. ペットシッターは「保管」

環境省、神奈川県、横浜市、東京都などの公的情報では、保管業の具体例としてペットシッターが明記されている。

保管の定義は概ね以下である。

> 保管を目的に顧客の動物を預かる業

該当例:

- ペットホテル
- 美容業者（動物を預かる場合）
- ペットシッター

したがって、PawMate 上で実際にペットの世話・散歩・訪問ケア・預かりを行うケアラーは、原則として第一種動物取扱業「保管」の登録が必要である。

### 2-3. 飼養施設がなくても対象

重要なのは、訪問型・出張型でも対象になる点である。

環境省・神奈川県ともに、代理販売、ペットシッター、出張訓練などは、動物の所有や飼養施設がない場合でも規制対象になると明記している。

つまり、以下はすべて登録対象になり得る。

- 飼い主宅へ訪問して世話をする
- 飼い主宅から散歩に連れ出す
- ケアラー宅で一時預かりする
- 出張でしつけ・訓練を行う

「店舗がない」「預かり施設がない」「個人だから」という理由では登録不要にならない。

## 3. PawMate の登場人物ごとの扱い

### 3-1. ケアラー

PawMate 上で有償・反復継続してペットケアを提供するケアラーは、第一種動物取扱業「保管」の登録を持つべきである。

サービス内容によっては「訓練」も必要になる可能性がある。

| サービス | 動物取扱業上の見立て |
|---|---|
| 散歩代行 | 保管 |
| 飼い主宅での食事・トイレ・見守り | 保管 |
| ケアラー宅での一時預かり | 保管 |
| 宿泊預かり | 保管 |
| しつけ・トレーニング | 訓練。預かりを伴う場合は保管も検討 |
| 動物看護・投薬補助 | 保管に加え、獣医療該当性に注意 |

PawMate は初期登録条件として、最低でも「保管」の登録を必須にするべきである。

### 3-2. PawMate 運営会社

PawMate 運営会社が自らペットを預からず、ケア契約の当事者にもならず、登録済みケアラーと飼い主をマッチングするだけであれば、運営会社自身は第一種動物取扱業「保管」には直ちには該当しない可能性がある。

ただし、これは確定ではない。実態として PawMate がペットケア事業者のように振る舞うと、行政から「PawMate が業として保管を行っている」と見られるリスクがある。

### 3-3. 飼い主

飼い主は自己のペットの所有者であり、通常は動物取扱業者ではない。ただし、飼い主が PawMate 外で反復継続して他人のペットを預かる側に回る場合は、登録対象になり得る。

## 4. 類似サービスの契約構造

### 4-1. DogHuggy

DogHuggy の利用規約では、以下の構造が明記されている。

- サービスは飼い主とドッグホストを結ぶオンラインプラットフォーム
- 運営会社はホスティング契約の当事者ではない
- ホスティング契約は飼い主とドッグホストの間で成立する
- 紛争は原則として飼い主とドッグホストの間で解決する
- 事前面談後、予約リクエスト、承認、支払い完了により契約成立

これは、運営会社が「保管」の当事者と見られないようにするための設計と考えられる。

ただし DogHuggy は「愛犬家による助け合い」色が強く、PawMate のように「有資格プロのみ」「業としての提供」を前提にする場合は、より厳格にケアラー側の登録確認が必要になる。

### 4-2. ぺっとりんぐ

ペットシッターマッチングアプリ「ぺっとりんぐ」の利用規約では、以下が確認できる。

- ペットシッターと飼育者をマッチングさせる場を提供する
- シッティング契約は飼育者とシッターの間で成立する
- 運営会社は個別契約の当事者ではない
- ペットシッター登録には第一種動物取扱業の登録証明提出が必要
- 前払決済後に飼育者とシッター間の個別契約が成立する

PawMate に最も近い参考事例は DogHuggy よりも、むしろこの構造である。

PawMate への示唆:

- ケアラー登録時に第一種動物取扱業の登録証明提出を必須化する
- 個別契約は飼い主とケアラーの間で成立すると明記する
- PawMate は個別契約の当事者ではないと明記する
- 決済を PawMate 内で行っても、契約当事者性を規約で分離する

## 5. PawMate が運営会社自身として登録対象になり得る危険な設計

以下の要素が強くなると、PawMate 運営会社自身が「保管業を営む者」と評価されるリスクが上がる。

### 5-1. PawMate がケア契約の当事者になる

危険な表示・契約:

- 「PawMate がペットをお預かりします」
- 「PawMate が散歩代行します」
- 飼い主との契約相手が PawMate になっている
- ケアラーが PawMate の履行補助者・スタッフとして扱われる

推奨:

- 「PawMate は登録ケアラーと飼い主をつなぐプラットフォームです」
- 「ケア契約は飼い主とケアラーの間で成立します」
- 「ケアラーは独立した個人事業主または事業者です」

### 5-2. PawMate がケアラーを雇用・派遣する

危険な設計:

- ケアラーを PawMate の従業員・アルバイトとして雇う
- PawMate がシフトを組む
- PawMate が利用者宅にスタッフを派遣する
- PawMate がケア内容を個別に指揮命令する

推奨:

- ケアラーは独立事業者として登録
- PawMate は予約・決済・安全基準・ガイドラインを提供
- 個別のケア実施判断はケアラーが行う

### 5-3. PawMate がサービス内容・価格・提供主体を完全に支配する

リスクが上がる要素:

- PawMate が一律価格を決める
- PawMate がケアラーを指名せず裏側で割り当てる
- 飼い主から見て誰が提供者か分からない
- ケアラー名・登録番号・契約主体が表示されない

推奨:

- ケアラーごとのプロフィールを表示
- 登録番号を表示
- ケアラーごとのサービス範囲・料金を表示
- 飼い主がケアラーを選ぶ
- 予約確定画面で契約相手を明示

### 5-4. PawMate が動物を一時的に占有・管理する

危険な設計:

- PawMate の施設で集合預かりをする
- PawMate がペットをいったん預かってケアラーへ引き渡す
- PawMate 名義で送迎・保管する
- PawMate がペットホテル機能を持つ

推奨:

- PawMate は動物を直接占有しない
- 送迎・預かりは登録済みケアラーが自ら提供する
- PawMate 施設を作る場合は、別途 PawMate 自身の第一種動物取扱業登録を検討する

## 6. PawMate に推奨する運営スキーム

### 6-1. 基本構造

```
PawMate 運営会社
  - プラットフォーム運営
  - ケアラー審査
  - 登録証確認
  - 予約・決済・メッセージ機能提供
  - 安全基準・事故対応フロー提供
  - 保険・保証制度の検討と、確認後の表示・運用

ケアラー
  - 第一種動物取扱業「保管」登録済み
  - 独立した個人事業主または法人
  - 飼い主と直接ケア契約を締結
  - 実際のペットケアを提供

飼い主
  - ケアラーを選択
  - ケアラーと直接契約
  - PawMate にサイト利用料・決済手数料等を支払う
```

### 6-2. 契約の分け方

PawMate では、最低限以下の規約を分けるべきである。

1. サービス利用規約
2. 飼い主規約
3. ケアラー規約
4. シッティング個別契約の標準条件
5. PawMate 安心保証規程
6. 事故対応規程
7. プライバシーポリシー

重要なのは、PawMate とユーザーの「プラットフォーム利用契約」と、飼い主とケアラーの「ケア提供契約」を分けることである。

### 6-3. 個別契約成立のタイミング

推奨:

```
飼い主がケアラーを選ぶ
  ↓
事前面談を申し込む
  ↓
事前面談を実施する
  ↓
飼い主が予約リクエストを送る
  ↓
ケアラーが承諾する
  ↓
飼い主が PawMate 内で決済する
  ↓
飼い主とケアラーの間で個別契約成立
```

予約確定画面に以下を表示する。

- 契約相手は PawMate ではなくケアラーであること
- ケアラーの氏名または屋号
- 第一種動物取扱業の登録番号
- 登録自治体
- 登録業種
- 保険加入状況
- PawMate 保証の対象条件

## 7. ケアラー登録要件

PawMate は「有資格プロのみ」を掲げるため、登録要件は強めにする。

### 必須

- 第一種動物取扱業「保管」の登録証
- 動物取扱責任者の確認
- 本人確認
- 反社チェック
- ペットシッター賠償責任保険加入
- 緊急連絡先
- 対応可能エリア
- 対応可能サービス
- 事故対応マニュアルへの同意

| サービス | 追加確認 |

| 散歩 | リード管理ルール、GPS記録同意、脱走歴確認 |

| ケアラー宅預かり | 飼養施設・住居での受入可否、頭数上限、近隣トラブル対策 |

| 投薬・シニアケア | 獣医療該当性、飼い主指示書、かかりつけ医情報 |

### 任意だが推奨

- 愛玩動物飼養管理士

## 9. 決済・手数料の設計

PawMate はデュアルフィーを想定している。

法務上は、決済を PawMate が扱うこと自体が直ちに動物取扱業該当性を決めるわけではない。ただし、決済の見せ方を誤ると「PawMate がケアサービスを販売している」ように見える。

推奨:

- 飼い主が支払う総額の内訳を表示する
- ケアラー報酬
- PawMate サービス利用料
- 決済手数料
- 保険・保証関連費用

表示例:

```
ケアラー報酬：4,000円
PawMate サービス利用料：280円
決済・保証関連費：xxx円
合計：4,xxx円
```

ケアラー側から徴収する手数料も、「PawMate がケアラーに案件紹介・予約決済・安全管理機能を提供する対価」として整理する。

## 10. 行政相談で確認すべき質問

神奈川県動物愛護センターまたは管轄自治体に、以下を確認する。

### PawMate 運営会社について

1. PawMate が動物を直接預からず、飼い主と登録済みケアラーをつなぐだけの場合、PawMate 運営会社自身に第一種動物取扱業登録は必要か
2. PawMate が予約・決済を代行する場合でも、個別契約が飼い主とケアラー間で成立するなら、PawMate は登録不要と整理できるか
3. PawMate がケアラー審査・登録証確認・保険確認・事故対応窓口を持つことは、保管業該当性を強めるか
4. PawMate が独自保証を提供することは、保管業該当性に影響するか
5. LPやアプリ上で避けるべき表示はあるか

### ケアラーについて

6. 訪問型ペットシッターは「保管」登録が必要という理解でよいか
7. 散歩代行のみでも「保管」登録が必要か
8. ケアラー宅での預かりと飼い主宅訪問で、登録や施設要件に違いはあるか
9. 「訓練」登録のみのドッグトレーナーが、散歩代行や訪問ケアを提供できるか
10. 「保管」登録を持つケアラーが、簡単なしつけ・トレーニングを提供する場合、訓練登録も必要か
11. 動物取扱責任者の要件として、チカ先生やHey!Dogs関係者の資格・実務経験は使えるか

### エリア・事業所について

12. ケアラーが藤沢・茅ヶ崎・鎌倉など複数市で訪問ケアを行う場合、登録自治体はどこになるか
13. ケアラーの事業所所在地とサービス提供先が異なる場合の扱い
14. 横浜市・川崎市・相模原市・横須賀市など、県ではなく市が窓口になる地域での扱い
15. 飼養施設なしの訪問型ケアラーに必要な書類

## 11. PawMate の初期方針

### フェーズ0〜1

PawMate は以下で始める。

```
運営会社：登録済みケアラーと飼い主をつなぐプラットフォーム
ケアラー：第一種動物取扱業「保管」登録済みのみ
契約：飼い主とケアラーの直接契約
決済：PawMate 内で実施
保険・保証：保険会社回答と規約設計が完了するまで外部表示しない
```

PM-RM-P0-004 の行政相談と PM-RM-P0-006 の保険相談が終わるまでは、登録済みケアラー候補の事前ヒアリングまでに留め、実取引・正式募集・予約受付は開始しない。

初期は、「保管」登録が未確認のトレーナーや一般愛犬家は登録させない。

チカ先生やHey!Dogs が候補であっても、以下を確認するまでは実取引に進めない。

- 保管業登録の有無
- 登録番号
- 登録自治体
- 登録業種
- 動物取扱責任者
- 保険加入状況
- 対応可能サービス

### フェーズ2以降

以下を検討する。

- 未登録だが資格・実務経験のある人への登録サポート
- 行政書士との提携
- ケアラー向け保管業登録ガイド
- PawMate 団体保険
- PawMate 研修修了制度

ただし、未登録者を「準ケアラー」として掲載し、実ケア前に登録すればよいという運用は避ける。利用者から見ると誤認を生みやすく、行政上も危険。

## 12. 規約に入れるべき条項

### サービス利用規約

- PawMate はオンラインプラットフォームである
- PawMate は個別のペットケア契約の当事者ではない
- ケア契約は飼い主とケアラーの間で成立する
- PawMate は登録証・保険等を確認するが、ケアラーの業務遂行を保証するものではない
- PawMate 経由外の取引は禁止
- PawMate 経由外の取引は保証・保険・サポート対象外

### ケアラー規約

- 第一種動物取扱業登録の維持義務
- 登録証・変更届の提出義務
- 保険加入維持義務
- 無断再委託禁止
- 事故時の即時報告義務
- ケア中の記録義務
- 登録取消・行政処分・保険失効時の即時通知義務
- PawMate 表示上の登録番号公開への同意

### 飼い主規約

- 既往症、攻撃性、脱走歴、ワクチン、投薬情報の告知義務
- 事前面談の実施義務
- 緊急時の動物病院搬送同意
- 鍵・住居情報の管理
- ペット起因の第三者損害に関する責任分担
- PawMate 保証の対象条件・除外条件

### 個別契約標準条件

- ケアラーが独立事業者として提供すること
- サービス内容
- 料金
- キャンセル
- 緊急時対応
- 損害賠償
- 保険
- 事故報告
- 免責

## 13. 残るリスク

### 13-1. 行政解釈リスク

自治体によって、プラットフォームの関与度に対する見方が異なる可能性がある。特に PawMate が審査・決済・事故対応、保険・保証設計を強く担う場合、単なる掲示板よりも関与度は高い。

対応:
- 営業開始前に事前相談する
- スキーム図・規約案・画面表示案を持参する
- 相談結果を議事メモ化する

### 13-2. 実態評価リスク

規約上はプラットフォームでも、実態として PawMate がサービス提供者に見えると危険。

対応:
- 表示、契約、請求書、領収書、予約画面で契約相手を明確にする
- ケアラーの登録番号を表示する
- PawMate スタッフという表現を使わない

### 13-3. ケアラー登録の継続確認

登録証や保険が失効したケアラーが活動すると危険。

対応:
- 登録証の有効期限管理
- 年1回の更新確認
- 行政処分・廃業・変更届の自己申告義務
- 保険証券の更新確認

## 15. 最終提案

PawMate は、以下の建て付けで進める。

```
PawMate は、第一種動物取扱業登録済みのケアラーと飼い主をつなぐプラットフォーム。
実際のケア契約は、飼い主とケアラーの間で成立する。
PawMate は、登録証確認、予約、決済、報告、事故対応支援を提供する。
保険・保証は、保険会社回答と規約設計が完了した後にだけ外部表示する。
```

初期フェーズでは、一般愛犬家や未登録ケアラーは扱わない。チカ先生ネットワークを活用する場合も、まず「保管」登録の有無を確認する。

この設計なら、PawMate の差別化である「有資格プロのみ」「信頼インフラ」「地域密着」を保ちながら、運営会社自身が保管業の主体と見られるリスクを下げられる。

ただし、最終判断は行政確認が必要である。営業開始前に、神奈川県動物愛護センターへ以下3点を持って相談する。

1. 事業スキーム図
2. 画面表示案
3. 利用規約・ケアラー規約・飼い主規約のドラフト
