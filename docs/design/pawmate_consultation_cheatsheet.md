## PawMateのスキーム（説明用）

```text
飼い主
  ↓ ケアラーを選択。個別ケア契約は飼い主とケアラー間で成立する想定
ケアラー
  - 実際の訪問ケア、散歩、預かり、しつけ相談等を提供
  - 初期は第一種動物取扱業の登録確認ができる人に限定する案
  ↑
PawMate運営者
  - プロフィール掲載
  - 登録情報確認
  - 予約、決済、メッセージ、ケア記録
  - 事故時連絡フローの整備
```

重要: 登録要否を断定してもらうのではなく、論点・管轄・必要資料・避けるべき表示を確認する。

---

## 必須5問

1. PawMateが直接預からず、飼い主と登録済みケアラーをつなぐ場合、PawMate運営者自身にも第一種動物取扱業登録が必要になる可能性があるか。
2. 予約、決済、メッセージ、登録証確認、事故時連絡フローをPawMateが提供することで、単なる紹介を超えて登録要否が変わる可能性があるか。
3. 訪問ケア、散歩、ケアラー宅での日帰り預かり、宿泊預かり、しつけ相談で、それぞれ「保管」「訓練」などの登録区分がどう関係するか。
4. アプリやLP上で表示すべき登録情報と、逆に避けるべき表現は何か。
5. Phase 1として小さく検証する場合、最低限どの条件を満たせばよいか。

---

## 追加で確認したい事項

**ケアラーの業種について**
- 散歩代行のみでも「保管」登録が必要か
- 飼い主宅訪問型と、ケアラー宅預かり型で、施設要件に違いはあるか
- 「訓練」登録のみのトレーナーが散歩代行・訪問ケアを提供できるか
- 「保管」登録者が簡単なしつけを行う場合、「訓練」登録も必要か
- 登録申請中の人を掲載してよいか。掲載可能な場合、予約受付や表示に制限はあるか

**エリアについて**
- 茅ヶ崎在住のケアラーが藤沢・鎌倉でもケアを提供する場合、登録窓口はどこか
- 飼養施設なしの訪問型ケアラーに必要な書類は何か

**表示について**
- プロフィールに表示すべき項目は、登録番号、登録種別、事業所名または氏名、有効期限のどれか
- 「登録確認済み」「登録申請中」「資格保有」などの表示で注意すべき点はあるか
- LP上で避けるべき表現はあるか

## 相談後の判断分岐

| 行政回答 | PawMate側の対応 |
|---|---|
| PawMate運営者にも登録が必要そう | Phase 1延期。行政書士・弁護士相談へ |
| 登録済みケアラー掲載型なら検討可能 | Phase 1進行候補 |
| 訪問・散歩も保管登録が必要そう | 初期ケアラー条件を「保管登録者」に固定 |
| ケアラー宅預かりは施設要件が重い | 初期サービスから預かりを外す |
| 訓練行為は別登録が必要そう | しつけ相談は初期から外す、または訓練登録者のみ |
| 市ごとに窓口が分かれる | 初期エリアを茅ヶ崎中心に限定 |
| 表示に登録番号等が必要 | PM-RM-P0-005の表示項目を確定 |
| 行政では判断不可と言われる | 行政書士・弁護士へ相談論点を渡す |
