# PM-RM-P1-002: ケアラーの保管業登録状況を確認・支援する

## Subtasks
- [ ] 各ケアラーの動物取扱業登録番号を収集する
- [ ] 登録種別が保管または訓練に該当するか確認する
- [ ] 登録有効期限を確認する
- [ ] 未登録者の人数を把握する
- [ ] 未登録者向けの登録手順を整理する
- [ ] 必要に応じて行政書士相談の導線を用意する
- [ ] 登録確認結果を管理表に反映する

## Acceptance Criteria
- [ ] フェーズ1で稼働するケアラーの登録状況が全員分確認できている
- [ ] 未登録者に対する支援方針が決まっている
