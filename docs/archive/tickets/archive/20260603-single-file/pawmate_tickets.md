## チケット設計ルール

| 項目 | 内容 |
|---|---|
| Epic | ロードマップ上のフェーズ |
| Ticket | 実行・検証・意思決定の単位 |
| Subtask | 実作業として着手できる粒度 |
| Gate | 次フェーズに進むための判定チケット |
| Priority | P0: 進行条件 / P1: 必須 / P2: 重要 / P3: 選択肢 |
| Status | Todo / Doing / Waiting / Done / Blocked |
