## 基本方針

**「広げる前に深める。深まったら広げる。」**

全国展開・機能追加・資金調達は後でいい。
まず茅ヶ崎で1件の取引を成立させることが最優先だ。
各フェーズには「次のフェーズに進む判断基準」を設ける。数字が基準を満たさなければ進まない。

## フェーズ1｜最初の取引を作る（2026年7〜9月）

**テーマ：「1件成立。仮説を検証する。」**

### 目標数値

| KPI | 目標 |
|-----|------|
| 登録ケアラー数 | 5〜10人 |
| 登録飼い主数 | 30〜50人 |
| 月間成約件数 | 50〜100件 |
| 月間GMV | 200,000〜400,000円 |
| 月間収益（デュアルフィー25%） | 50,000〜100,000円 |
| リピート率 | 40%以上（目標60%への第一歩） |

### やること

**供給側（ケアラー）**
- チカ先生ネットワークから有資格ケアラー5〜10人を確保
- 全員の保管業登録状況を確認・未登録者のサポート
- プロフィール作成・撮影のサポート（最初は一緒にやる）
- 最初の1件を「一緒に成功させる」体験を作る

**需要側（飼い主）**
- Keiさんの近隣ペット飼育者に直接声をかける
- チカ先生の既存顧客への案内（チカ先生経由）
- 広告はやらない。口コミだけで最初の30人を作る

**プロダクト**
- 報告カード機能（GPS＋写真）の実装
- リピート率の表示をプロフィールに追加
- Meet & Greet（事前面談）の予約フローを実装
- エスクロー決済（Stripe Connect）の本番環境構築

**オペレーション**
- 初回トラブル対応フローの文書化
- ケアラー向けマニュアルの作成（ケア中の記録方法・緊急時対応）

### フェーズ1の完了条件（次フェーズへの進条件）

```
✓ 月間成約件数 100件以上
✓ リピート率 40%以上
✓ 重大事故ゼロ
✓ ケアラーの継続率 80%以上（離脱していない）
✓ 飼い主から自発的な口コミが出ている
```

## 各フェーズの注意点

### やってはいけないこと

**フェーズ1でやってはいけないこと：**
- 広告にお金をかけること（口コミで検証する）
- エリアを広げること（茅ヶ崎に集中する）
- 機能を増やしすぎること（動く最小限で検証する）

**フェーズ2でやってはいけないこと：**
- リピート率が55%を超える前に大規模集客すること
- ケアラーの質を犠牲にして数を増やすこと
- 競合（ペットゴー+DogHuggy）を意識して戦略を変えること

**フェーズ3でやってはいけないこと：**
- 月次黒字が出る前に資金調達に走ること
- 湘南が固まる前に他地域に手を出すこと
