## 1. β期間の運用体制

| 役割 | 担当 | 連絡先 | 対応時間 |
|---|---|---|---|
| **運用責任者（社長）** | 嶋崎恵一郎 | LINE / メール | 9:00〜21:00 |
| **ケアラー窓口** | 嶋崎恵一郎 | 同上 | 同上 |
| **飼い主窓口** | 嶋崎恵一郎 | 同上 | 同上 |
| **緊急時（21時以降）** | 嶋崎恵一郎 | 電話 | 24時間（緊急のみ） |

> β期間はすべての問い合わせを嶋崎が一元管理する。専任CSスタッフ不在のため、対応遅れが発生する場合は事前に飼い主・ケアラー双方へ周知する。

## 2. 安全確認フロー

### 2-1. サービス開始前の安全確認（必須）

**ケアラー側チェックリスト（初回サービス前）**
- [ ] 動物取扱業登録証の有効期限確認済み
- [ ] 本人確認書類提出済み
- [ ] 緊急連絡先（第三者）登録済み
- [ ] Meet & Greet実施済み（対象ペットと初回対面完了）
- [ ] 対象ペットのアレルギー・持病・投薬情報を飼い主から受領済み
- [ ] サービス当日の天候・体調による中止基準を飼い主と合意済み

**飼い主側チェックリスト（初回サービス前）**
- [ ] ペットの健康状態（直近のワクチン接種・持病）をケアラーに共有済み
- [ ] 緊急時の動物病院（名称・電話番号）をケアラーに伝達済み
- [ ] 鍵の受け渡し方法・合鍵の扱い方を合意済み（訪問ケア・宿泊の場合）
- [ ] ケアラーが入室できない場所・触れてはいけないものを伝達済み
- [ ] フードの量・与え方・禁止食材をケアラーに共有済み

### 2-2. サービス中の安全確認

- ケアラーはサービス開始時に「開始しました」メッセージを飼い主に送る
- 散歩代行（60分以上）・訪問ケア（60分）では中間報告（写真1枚以上）を送る
- 宿泊お預かりでは朝晩2回の状態報告を送る
- 異常を発見した場合は即座に飼い主へ連絡する（後述: 緊急時対応フロー）

### 2-3. サービス完了確認

- ケアラーはサービス完了後30分以内に「完了しました＋写真」を飼い主に送る
- 飼い主はアプリ上で「サービス完了」を確認・評価する
- 問題がある場合はその場でケアラーに直接連絡し、解決しない場合は嶋崎に連絡

## 3. 緊急時対応フロー

### 3-1. ペットに関する緊急事態

**発生事例**: ペットの体調急変・怪我・脱走・行方不明・異物誤食など

```
ケアラーが異常を発見
    ↓
①  即座に飼い主に電話（つながらない場合LINEでも連絡）
    ↓
②  状況に応じて最寄りの動物病院に連れて行く
    ※ 飼い主から事前に聞いた病院を最優先。不明な場合は最寄りの救急対応病院
    ↓
③  嶋崎（運用責任者）に報告
    ↓
④  処置・費用の記録（領収書保管）
    ↓
⑤  事後レポートをNotionに記録（後述: セクション5）
```

**飼い主が連絡に出ない場合の判断基準**
- 軽微な擦り傷・一時的な嘔吐 → 様子見。30分後に再連絡。記録は残す
- 出血・高熱・意識混濁・骨折疑い → 飼い主の返答を待たず動物病院へ。移動中に再度連絡
- 脱走・行方不明 → 即座にエリア捜索開始＋嶋崎に連絡

> `[法務確認要]` 緊急医療費の一時立替・求償範囲については利用規約に明記が必要。β版では「実費は飼い主負担、事前合意前提」として口頭運用とする。

### 3-2. ケアラーに関する緊急事態

**発生事例**: ケアラーの体調不良・怪我・交通事故・連絡不通

```
ケアラーが対応困難と判断
    ↓
①  飼い主に即座に連絡（嶋崎が代理連絡も可）
    ↓
②  代替ケアラーのアサインを試みる（β期間中は嶋崎が直接対応することも含む）
    ↓
③  代替不可の場合は飼い主に謝罪・払い戻し対応
    ↓
④  事後レポートをNotionに記録
```

### 3-3. 飼い主との連絡不通

**サービス前日〜当日に飼い主と連絡が取れない場合**

- 予約3時間前までに連絡がつかない場合 → サービス実施を一時保留
- 嶋崎に連絡 → 状況判断の上、実施可否を決定
- 宿泊お預かりでペットが自宅にいる場合は、安全確認のため訪問継続とする

## 4. キャンセルポリシー

### 4-1. 飼い主からのキャンセル

| キャンセルタイミング | 対応 |
|---|---|
| サービス開始**2日前（48時間前）まで** | 無料キャンセル |
| サービス開始**24時間前〜48時間前** | キャンセル料なし（β特別対応）。ケアラーに謝礼として¥500相当のギフトカードを検討 |
| サービス開始**24時間以内** | キャンセル料なし（β特別対応）。ただし繰り返しの場合は次回から制限 |
| **当日（サービス開始後）** | 料金の50%を請求 `[法務確認要]` |

> β期間中はキャンセル料の強制徴収は行わない。飼い主との関係を優先し、状況を把握した上で個別対応する。

### 4-2. ケアラーからのキャンセル

| キャンセルタイミング | 対応 |
|---|---|
| サービス開始**48時間前まで** | 代替ケアラーのアサインを試みる。不可の場合は全額払い戻し |
| サービス開始**24時間以内** | 同上。ケアラーの評価スコアに影響あり（将来実装） |
| **当日ドタキャン** | 全額払い戻し＋嶋崎からの謝罪連絡。ケアラー資格停止を検討 |

### 4-3. 返金処理（β版）

> `[法務確認要]` 現状のβ版では本番決済未接続のため、実際の返金はテスト環境内の操作となる。実ユーザーへの金銭のやり取りが発生する場合は、銀行振込またはPayPayで対応する。返金ポリシーは利用規約に明記する必要あり。

返金手順（暫定）:
1. 払い戻し対象を確認し、飼い主・ケアラーに連絡
2. 金額・振込先を確認
3. 嶋崎が手動で振込
4. 完了をNotionに記録

## 5. 問い合わせ・トラブル記録方法

### 5-1. 問い合わせ受付チャネル

| チャネル | 対応範囲 | 対応時間 |
|---|---|---|
| LINE（個別メッセージ） | 全般 | 9:00〜21:00（緊急は24時間） |
| メール | 詳細な問い合わせ | 24時間受付・翌営業日回答 |
| アプリ内メッセージ | サービス関連 | 随時（通知確認は9:00〜21:00） |

### 5-2. 問い合わせ対応フロー

```
問い合わせ受信
    ↓
① 受信後30分以内に「受け付けました」返信（21時以降は翌朝）
    ↓
② 内容分類（サービス品質 / 技術問題 / キャンセル / 安全 / その他）
    ↓
③ 対応・解決
    ↓
④ Notionインシデントログに記録（後述）
```

### 5-3. Notionインシデントログ（記録フォーマット）

以下のフォーマットでNotionの専用ページ（または既存チケットのコメント）に記録する。

```
【インシデント記録】
日時: YYYY-MM-DD HH:MM
報告者: （飼い主 / ケアラー / 運用担当）
関係者: 飼い主ID / ケアラー名
サービス種別: 散歩代行 / 訪問ケア / 宿泊
内容: （具体的な事象を200字以内で）
重大度: 🔴 重大 / 🟡 軽微 / 🟢 情報
対応内容: （実施した対応を記述）
解決状態: 解決済み / 対応中 / エスカレーション中
再発防止策: （あれば）
```

### 5-4. インシデントの重大度分類

| 重大度 | 基準 | 対応期限 |
|---|---|---|
| 🔴 重大 | ペットの怪我・病院送り・脱走・金銭被害・ケアラー失踪 | 即時（24時間以内に関係者全員へ報告） |
| 🟡 軽微 | サービス品質への不満・遅刻・コミュニケーション問題 | 24時間以内に連絡・48時間以内に解決 |
| 🟢 情報 | 機能要望・改善提案・一般的な質問 | 1週間以内に返答 |
