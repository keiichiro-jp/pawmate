# PawMate 行政相談パック
くじら舎 ／ 2026.06.02

---

## 目的

PM-RM-P0-004 は、PawMate のサービス開始可否を一気に判定するためではなく、行政上の地雷を踏まずに Phase 1 の検証を行えるスキームを確認するためのゲートである。

相談のゴールは「登録不要」と言ってもらうことではない。次の3点を明確にする。

1. PawMate 運営者自身の第一種動物取扱業登録要否に影響する要素
2. Phase 1 で許容されるサービス範囲、ケアラー条件、表示条件
3. 行政では判断できず、行政書士・弁護士へ渡すべき論点

## 名乗り方

```text
茅ヶ崎・湘南エリアで、飼い主と有資格者・経験者のペットケア提供者をつなぐ小規模な仕組み「PawMate」を構想している者です。
まだサービス開始前で、第一種動物取扱業の登録区分、表示、契約主体、責任範囲について事前に確認したく、ご相談しました。
```

避ける言い方:
- PawMate が預かるサービスです
- PawMate スタッフが訪問します
- 保険付き、保証あり、安全を保証します
- 登録不要で進められるか確認したいです

## 受付フェーズのスクリプト

```text
お世話になります。
第一種動物取扱業、特にペットシッターや一時預かりに関する事前相談でお電話しました。
担当部署または相談方法を確認したいです。
```

内容を聞かれた場合:

```text
茅ヶ崎・湘南周辺で、飼い主さんと登録済み、または登録確認可能なケアラーさんをつなぐ予約・プロフィール掲載・決済・メッセージ・記録の仕組みを検討しています。
PawMate自身が直接動物を預かる形ではなく、実際のケアは個別のケアラーさんが行う想定です。

ただし、訪問ケア、散歩、ケアラー宅での日帰り預かり、宿泊預かり、簡単なしつけ相談など、提供パターンによって登録区分が変わる可能性があると思い、事前に確認したいです。
```

事業所・提供場所を聞かれた場合:

```text
運営主体は茅ヶ崎市内を想定しています。初期提供エリアも茅ヶ崎・湘南周辺を想定しています。
第一種動物取扱業については、横浜市・川崎市・相模原市・横須賀市は各市窓口、それ以外の県内は神奈川県動物愛護センターが窓口と認識しています。
まず茅ヶ崎を対象にした場合の相談先として御センターでよいか確認したいです。
```

## 必須5問

1. PawMate が直接預からず、飼い主と登録済みケアラーをつなぐ場合、PawMate 運営者自身にも第一種動物取扱業登録が必要になる可能性があるか。
2. 予約、決済、メッセージ、登録証確認、事故時連絡フローを PawMate が提供することで、単なる紹介を超えて登録要否が変わる可能性があるか。
3. 訪問ケア、散歩、ケアラー宅での日帰り預かり、宿泊預かり、しつけ相談で、それぞれ「保管」「訓練」などの登録区分がどう関係するか。
4. アプリやLP上で表示すべき登録情報と、逆に避けるべき表現は何か。
5. Phase 1 として小さく検証する場合、最低限どの条件を満たせばよいか。

時間があれば聞くこと:
- 登録申請中のケアラーを掲載してよいか。掲載できる場合、予約受付や表示に制限はあるか。
- 登録証の写し、有効期限、登録種別、事業所名、動物取扱責任者名のうち、プロフィールに表示すべき項目は何か。
- 事業所所在地、ケアラー所在地、サービス提供地が異なる場合、どの自治体窓口に確認すべきか。
- ケアラー宅預かりと飼い主宅訪問で、施設要件や届出・変更手続きに違いがあるか。

## 事前送付用 1枚資料

### 1. サービス概要

PawMate は、茅ヶ崎・湘南周辺で、飼い主と有資格者・経験者・登録確認済みケアラーをつなぐ小規模なペットケア予約・相談プラットフォーム。

### 2. PawMate の役割

プロフィール掲載、登録情報確認、予約、決済、メッセージ、ケア記録、事故時連絡フローの整備。

### 3. ケアラーの役割

実際の訪問ケア、散歩、預かり、しつけ相談等を提供。初期は第一種動物取扱業の登録確認ができる人に限定する案。

### 4. 飼い主との契約関係

PawMate 利用規約に同意。個別ケア契約は飼い主とケアラー間で成立する想定。ただし、行政確認前の仮説。

### 5. 提供パターン

| パターン | 内容 | 初期対応方針 |
|---|---|---|
| 訪問ケア | 飼い主宅で給餌・トイレ・見守り | 登録区分確認 |
| 散歩 | 飼い主宅から犬を預かり散歩 | 登録区分確認 |
| 日帰り預かり | ケアラー宅で一時預かり | 慎重。初期除外も検討 |
| 宿泊預かり | ケアラー宅で宿泊預かり | かなり慎重。初期除外候補 |
| しつけ相談 | 簡単な行動相談・トレーニング | 訓練登録との関係確認 |

### 6. 未確定事項

PawMate 運営者自身の登録要否、ケアラー登録区分、表示項目、契約主体、保険スキーム。

## 想定回答と対応

| 行政回答 | PawMate 側の対応 |
|---|---|
| 内容によって判断が変わるため資料提出を求められる | 1枚資料、提供パターン表、契約関係図、画面表示案を送る |
| PawMate 運営者にも登録が必要そう | Phase 1 延期。行政書士・弁護士相談へ |
| 登録済みケアラー掲載型なら検討可能 | Phase 1 進行候補 |
| 訪問・散歩も保管登録が必要そう | 初期ケアラー条件を「保管登録者」に固定 |
| ケアラー宅預かりは施設要件が重い | 初期サービスから日帰り・宿泊預かりを外す |
| 訓練行為は別登録が必要そう | しつけ相談は初期から外す、または訓練登録者のみ |
| 市ごとに窓口が分かれる | 初期エリアを茅ヶ崎中心に限定し、エリア拡大時に窓口確認を必須化 |
| 表示に登録番号等が必要 | PM-RM-P0-005 の表示項目を行政回答に合わせて確定 |
| 行政では判断不可と言われる | 行政書士・弁護士へ相談論点を渡す |

## Phase 1 の暫定安全線

行政相談の結果が出るまで、実取引・募集・予約受付は止める。

事前ヒアリングとして実施できる範囲:
- 登録済みケアラー候補の候補者ヒアリング
- 動物取扱業登録番号、登録種別、有効期限、保険加入状況の確認
- 飼い主候補への課題ヒアリング
- LPやプロトタイプの内部検証

外部向けに出さない表現:
- PawMate が預かる
- PawMate スタッフが訪問する
- 保険付き
- 保証あり
- 登録済みケアラーのみで安心
- 行政確認済み
