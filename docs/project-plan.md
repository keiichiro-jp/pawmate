# PawMate — Project Plan

## 1. 基本情報

| 項目 | 内容 |
|---|---|
| プロジェクト名 | PawMate |
| 作成日 | 2026-06-09 |
| 作成者 | Codex / secretary |
| 責任者 | 社長 |
| 関係者 | 社長、ケアラー候補、β参加飼い主、湘南エリアの紹介者 |
| 背景 | 飼い主が「知らない人に大切なペットを預ける不安」を持つ中、信頼を可視化した限定βで仮説検証する必要がある |
| 目的 | 湘南エリア限定の招待制βで、初成約と NPS を確認し、定期契約βへ進む条件を見極める |
| 概要 | 有資格ケアラーと飼い主をつなぐペットケアマッチングサービスのβローンチ・検証計画 |

## 2. 目標・成果物

| 項目 | 内容 |
|---|---|
| 達成したい目標 | 2026-09-30 までに招待制βを開始し、成約 10 件・NPS 30 以上・リピート 1 件を検証する |
| 成功基準・KPI | 飼い主 5 名、ケアラー 3 名、初成約 1 件、成約累計 10 件、NPS 30 以上 |
| 最終成果物 | β候補者リスト、招待フロー、初成約記録、β検証レポート、改善リスト |
| 対象範囲 | 湘南エリア、招待制β、信頼スコア、初回マッチング、NPS・UX 課題記録 |
| 対象外範囲 | 全国展開、ケアラー大量登録、犬以外への過度な拡張、周辺機能の大量追加 |

## 8. リスク管理

| リスク | 発生可能性 | 影響度 | 対応策 | エスカレーション |
|---|---|---|---|---|
| ケアラー不足 | 高 | 高 | 有資格者の紹介ルートを優先確保する | 社長 |
| 信頼不安が解消しない | 中 | 高 | 信頼スコア、レビュー、本人確認を強化する | β参加者 → 社長 |
| 初回トラブル | 中 | 高 | 招待制・小規模運用に限定し、成約ごとにレビューする | 社長判断 |

## 9. 品質・完了条件

| 項目 | 基準 |
|---|---|
| 品質基準 | 飼い主とケアラーが不安なく初回マッチングを完了できる |
| レビュー方法 | β参加者レビュー、成約後ヒアリング、NPS、主要 UX 課題レビュー |
| 検収条件 | M2 の成約数、NPS、リピート、UX 問題解消を記録し、`status.md` に Evidence ID を残している |
| 完了判定基準 | M2 達成。定期契約βへ進むか、スコープを見直すかを判断できる状態 |
