## アプリで実際にケアラーを登録する手順

### 前提確認

PAW-T-001の実装により、以下がすでに動作状態：
- 信頼スコア計算ロジック（`calcTrustScore()`）実装済み
- 管理者審査パネル（`/admin` → 審査タブ）実装済み
- ケアラー側の受依頼フロー実装済み

---

### STEP 1: ケアラーへの登録案内

ケアラー候補者に以下URLを案内し、`/register` からアカウント登録を依頼：

```
登録URL: https://<本番ドメイン>/register
（現在はプロトタイプ: npm run dev → http://localhost:5173/register）
```

ケアラーが入力する情報：
- 表示名、自己紹介
- 活動エリア（茅ヶ崎・藤沢・鎌倉・平塚・辻堂から選択）
- 第一種動物取扱業 登録番号・種別・有効期限
- 提供サービス（散歩代行 / 訪問ケア / 宿泊お預かり）
- 料金設定
- 保有資格

---

### STEP 2: 管理者審査

1. `/admin` にアクセス → 「審査」タブを開く
2. 申請者リストにケアラーが表示される
3. 審査内容を確認：
   - 登録番号が「神奈川県 第12-XXXX号」形式か
   - 有効期限が有効期間内か
   - リスク評価（低/中）を確認
4. **「承認」ボタン**を押して公開状態にする

---

### STEP 3: 信頼スコア確認

承認後、ケアラー一覧ページ（`/search`）で：
- 各ケアラーカードに信頼スコア（0〜100）が表示されること確認
- スコア内訳：
  - 登録情報確認済み: +40pt
  - 資格（1件10pt × 最大2件）: +20pt
  - リピート率80%以上: +25pt
  - 評価4.8以上: +15pt

---

### STEP 4: ケアラー側フロー動作確認（デモアカウント）

デモデータ（`src/data/pawmateData.ts` の `carers` 配列）で確認済み：

| ケアラー名 | 信頼スコア | 資格 | 動作確認 |
|---------|---------|-----|--------|
| 伊藤 美咲 | 90/100 | JKC公認訓練士・ペット救急救命士 | ✅ |
| 中村 健太 | 85/100 | 愛玩動物飼養管理士1級・認定動物看護師 | ✅ |
| 佐藤 彩香 | 80/100 | 警察犬協会公認訓練士 | ✅ |

受依頼フローの確認項目：
- [ ] ケアラーがログイン後、自分の予約一覧を確認できる
- [ ] 依頼受付/辞退のアクションが動作する
- [ ] Meet & Greet リクエストへの返答ができる

---

## ⚠️ 実際の3名確保には人力アクションが必要

以下は**管理者（kei）が実施**する必要があります：

1. `carer-recruitment-kit.md` のテンプレートを使い実際のケアラーにDM送信
2. オンライン面談（30分）を実施
3. 上記STEPでアプリに登録・承認
4. ケアラー側に受依頼フローのテスト実施を依頼

技術的なアプリ準備は完了しています。残作業はすべて営業・人対人のコミュニケーションです。
