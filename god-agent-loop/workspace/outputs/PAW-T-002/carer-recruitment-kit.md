## ケアラー登録プロフィールの記入サポート

候補者が見つかったら、以下の情報を収集してアプリに登録：

1. 表示名
2. 自己紹介文（経験・得意なケア・ペットへの想い）
3. 活動エリア（茅ヶ崎 / 藤沢 / 鎌倉 / 平塚 / 辻堂）
4. 第一種動物取扱業 登録番号・登録種別
5. 登録証の有効期限
6. 提供サービス（散歩代行 / 訪問ケア / 宿泊お預かり）
7. 料金設定（時給・宿泊）
8. 保有資格・経験

登録後、管理パネル（`/admin` → 審査タブ）で承認操作をして公開状態にする。
