# PAW-GROW-001: LP先行登録導線変更設計書

**ステータス**: 完了  
**作成日**: 2026-06-28  
**担当**: designer-agent + writer-agent  
**対象ファイル**: `src/App.tsx` のヒーローセクション・ナビゲーション・登録CTA

---

## 目的

「無料登録」という心理ハードルの高い導線から、  
「近くで使えるか確認する」という低ハードルな先行登録導線へ変更し、  
飼い主・ケアラーそれぞれの入口を明確に分ける。

---

## 現状 vs. 変更後

### ナビゲーションCTA

| 箇所 | 現状 | 変更後 |
|---|---|---|
| ナビ右上ボタン | `無料登録` | `先行登録（無料）` |
| ナビ右上ボタン（サブ） | `ログイン` | `ログイン` ← 変更なし |

### ヒーローセクション（飼い主向け）

#### アイコピー（eyebrow）
- **現状**: `登録情報確認型 · 湘南エリア先行`
- **変更後**: `湘南エリア先行 · 有資格ケアラーのみ登録`

#### H1キャッチコピー
- **現状**: `信頼できるプロが、いつもの場所で、いつものように。`
- **変更後**: `近くに、頼れるプロが、いる安心。`（変更）  
  ※ サブコピーで湘南エリアを訴求する

#### リードコピー
- **現状**: `湘南で暮らす有資格のケアラーが、ペットの日常をそっと支えます。...`
- **変更後**:
  ```
  湘南エリアで使えるか、まず確認してみませんか。
  旅行・出張・体調不良のとき、信頼できる有資格ケアラーがそばにいる安心を。
  先行登録で、エリアに合ったケアラーをご紹介します。
  ```

#### CTAボタン（ファーストビュー）

| ボタン種別 | 現状 | 変更後 |
|---|---|---|
| Primary（飼い主） | `ケアラーを探す` | `近くで使えるか確認する 🐾` |
| Ghost（ケアラー） | `プロとして参加する` | `ケアラーとして登録する` |

#### エリア確認フォーム（ヒーローサーチカード）

現状の検索フォーム（日時・サービス・エリア選択）を、先行登録フォームに転換する。

**変更後の入力項目**:
1. `お住まいのエリア` — セレクト（茅ヶ崎 / 藤沢 / 鎌倉 / 辻堂 / 平塚 / その他）
2. `ペット種別` — セレクト（犬 / 猫 / その他）
3. `希望サービス` — マルチセレクト（散歩 / 訪問ケア / 宿泊 / デイケア）
4. `メールアドレス` — text input
5. ボタン: `エリアのケアラーを確認する →`

**フォーム送信後**:
- 「✓ 登録を受け付けました。エリアの状況をメールでご連絡します。」

## 追加セクション設計

### 「こんな時に使える」セクション（ヒーロー下）

```
こんな時に使えます

🧳 急な出張で犬の散歩ができないとき
✈️  家族旅行でペットを預けたいとき
🤒 体調不良で世話が難しいとき
🏠 毎日の訪問ケアを依頼したいとき
🐕 ペットホテルが苦手な子の選択肢として
```

実装: 横スクロールカードまたはアイコン+テキストのグリッド（既存UIに合わせる）

### 「先行登録のメリット」セクション

```
先行登録するとできること

✓ エリアにいるケアラーをいち早く確認
✓ サービス開始時に優先的にご案内
✓ 初回利用クーポンの対象（準備中）
✓ ケアラーへの要望を事前に伝えられる
```

### 信頼訴求バナー（ヒーロー内 or 直下）

```
🔍 全ケアラー、資格・保険・本人確認済み
📍 湘南エリア在住者のみ登録可能
⭐ リアルな評価・口コミを公開
```
