## 2. 審査項目チェックリスト

以下の全項目をケアラー登録時に確認する。**太字**は必須項目。

### 2-1. 法的要件（必須）

- [ ] **第一種動物取扱業 登録証を保有していること**
- [ ] **登録番号が神奈川県発行であること**（例: 神奈川県 第12-XXXX号）
- [ ] **登録の有効期限が切れていないこと**（更新期限を目視確認）
- [ ] **提供するサービスに対応する登録種別があること**
  - 保管: 訪問ケア・宿泊お預かり
  - 訓練: 散歩代行（訓練行為が伴う場合）
  - ※散歩代行のみであれば保管登録で対応可能だが、行政確認結果に準拠

### 2-2. 身元確認

- [ ] **本人確認書類（運転免許証 or マイナンバーカード）のコピー提出**
- [ ] **顔写真（プロフィール掲載用）の提出**
- [ ] **緊急連絡先の確認**（本人以外の連絡先1名）
- [ ] SNSアカウント or 活動実績URL（任意だがリスク評価に使用）

### 2-3. スキル・経験確認

- [ ] **保有資格の証明書コピー提出**（資格がある場合）
- [ ] 過去のケア経験年数の申告（1年以上推奨）
- [ ] 対応可能なペット種別の確認（犬 / 猫 / 小動物 / シニア / 投薬対応）
- [ ] 投薬対応経験の有無（訪問ケア・宿泊に必要）

### 2-4. 稼働条件確認（β期間中: 2026年7月〜8月）

- [ ] **週何日対応可能か（最低2日以上）**
- [ ] **対応時間帯（朝/昼/夜の希望）**
- [ ] **β期間中（2〜4週間）の継続コミット確認**
- [ ] Meet & Greetへの対応意思の確認
- [ ] 急なキャンセル時の対応方針の確認
- [ ] スマートフォン操作可否（Safari/iOS動作確認用）

### 2-5. リスク評価（管理者確認）

| リスク項目 | 低 | 中 | 高 |
|---|---|---|---|
| 登録証の有効期限 | 1年以上残存 | 6ヶ月〜1年 | 6ヶ月以内 |
| 身元確認書類 | 提出済み | 準備中 | 未提出 |
| ケア経験年数 | 3年以上 | 1〜3年 | 1年未満 |
| 過去トラブル自己申告 | なし | 軽微 | あり |

- リスク「高」が1項目でもある場合は承認を保留し、追加確認を実施
- リスク「中」が複数ある場合も要確認
